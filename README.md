# Football Auction — Android

مشروع Android أولي للعبة مزادات كرة قدم، بواجهة عربية داكنة ويعمل أثناء اللعب دون اتصال.

## الموجود حاليًا
- مزاد 5 لاعبين بميزانية 100 مليون.
- مزاد 11 لاعبًا بميزانية 200 مليون.
- اختيار عشوائي من قاعدة بيانات محلية مدمجة.
- شراء اللاعب مع منع تجاوز الميزانية.
- لعبة تخمين اللاعب.
- حفظ نقاط التخمين محليًا على الجهاز.
- لا توجد صلاحية إنترنت في التطبيق.

## إنشاء APK
### الطريقة الأولى: Android Studio
1. فك ضغط الملف.
2. افتح مجلد `FootballAuctionAndroid` من Android Studio.
3. انتظر إعداد Gradle وتنزيل إضافات البناء أول مرة (قد يتطلب ذلك إنترنت).
4. اختر Build ثم Build Bundle(s) / APK(s) ثم Build APK(s).
5. ستجد الملف في `app/build/outputs/apk/debug/app-debug.apk`.

### الطريقة الثانية: بناء APK تلقائيًا عبر GitHub
1. أنشئ مستودع GitHub جديدًا وارفع محتويات هذا المجلد إليه.
2. افتح تبويب Actions.
3. شغّل مهمة `Build Football Auction APK` أو ادفع تحديثًا إلى فرع `main`.
4. افتح نتيجة التشغيل الناجحة ثم نزّل Artifact باسم `Football-Auction-debug-apk`.
5. فك ضغط الـ Artifact وثبّت `app-debug.apk` على هاتف Android.

## حدود النسخة
هذه نسخة أولية قابلة للتطوير وليست قاعدة بيانات تضم كل لاعب كرة قدم في التاريخ. الأسماء والتقييمات والأسعار بيانات لعبة تقريبية وليست أسعار انتقالات رسمية أو تقييمات مباشرة. لا توجد صور لاعبين مضمنة حاليًا، لأن الصور يجب إضافتها كملفات محلية مرخصة حتى تظهر دون إنترنت.
